# 🎨 Artify — Art Supplies Store

Artify is a web development project for an online art supplies store. It allows users to create accounts, log in, browse art products, and interact with the website.

## ✨ Features

- User Sign Up and Login
- Homepage and About Us page
- Product browsing and editing
- Contact Us page
- User feedback
- MySQL database integration

## 🛠️ Technologies Used

- HTML
- CSS
- PHP
- MySQL

## 📁 Project Structure

- `html/` — PHP pages and website functionality
- `css/` — Website styling
- `image/` — Images and visual assets
- `iatask.sql` — Database export

## ⚙️ Local Setup

1. Install XAMPP.
2. Copy the project into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import `iatask.sql` into phpMyAdmin.
5. Configure the database connection in `connect.php`.
6. Open the project through your local server.
